## Reporting a Vulnerability

The IBP Timetable Platform team takes security seriously. If you discover a vulnerability or potential exploit:

1. **Do not** report the issue publicly via GitHub Issues.
2. Please email details to `security@ibptimebook.example.com` or create a private GitHub Security Advisory.
3. Include the following details:
   - Type of issue (e.g. JWT token leakage, solver DoS, SQL injection).
   - Step-by-step reproduction instructions or a minimal proof of concept.
   - Impact assessment on multi-tenant isolation or computational resources.

We will acknowledge receipt within 48 hours and work with you to patch and disclose the issue responsibly.
